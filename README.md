# tix 工单系统

> 公司内部小团队使用的工单系统：登记工单、处理备注、搜索筛选、统计看板、标记处理并自动归档。

**架构**：后端 Go（标准库 `net/http` + SQLite）提供 JSON REST API；前端 React 19 + Tailwind CSS v4 + shadcn/ui（图表 ECharts 按需）构建为 SPA，经 `embed.FS` 打进 Go 二进制。**单二进制部署**，运行时零外部依赖。

## 快速开始

```bash
./build.sh          # 构建前端 + 编译（默认当前平台）
./tix               # 默认 http://localhost:8881
```

- **管理端**：`http://localhost:8881`（默认账号 `admin` / `admin123`，可用 `-password` 或 `TIX_PASSWORD` 覆盖；登录后请立即在「设置 → 用户管理」修改密码）
- **报修提交页（发给他人）**：`http://localhost:8881/submit`
- **反向代理部署**：加 `-trust-proxy` 才会信任 `X-Forwarded-For` 头获取真实 IP（直连部署切勿开启，否则限流可被伪造头绕过）

开发模式（前后端分离，热更新）：

```bash
pnpm --dir web dev    # Vite :5173
go run .              # Go 后端 :8881
```

## 功能概览

- **管理端**：仪表盘（统计卡 + 分类分布图）、工单列表（分页 + 多条件筛选）、详情页（完整内容 + 备注时间线）、新建/编辑、分类管理、CSV 导出
- **报修提交页**：无侧边栏的纯净路由，纯表单，手机优先，适合发给他人填报
- **处理记录**：标记已处理时附解决备注，详情页可追加备注
- **分类可配置**：设置页增删改、排序、改颜色、启停
- **消息推送**：统一推送模块 + PushPlus 微信推送渠道（设置页配置 Token / 群组编码，可发送测试消息）；定期待处理工单汇总为规划中功能，将复用同一通道
- **集成 API Key**：设置页一键生成，外部工具（如时间规划助手）携带 `X-API-Key` 请求头即可免登录读取工单，等效操作员权限
- **主题切换**：顶部导航栏一键切换亮色 / 暗色模式
- **工单编号**：`T-YYYYMMDD-NNNN`（如 `T-20260818-0001`）
- **SQLite 单文件存储**：备份建议先停机再复制 `tix.db`（WAL 模式含 `-wal`/`-shm` 文件），或使用 `VACUUM INTO` 在线导出快照；启动时自动幂等迁移
